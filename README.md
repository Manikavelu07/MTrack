🚀 Overview
MTrack is a personal finance dashboard designed to track, analyze, and visualize investment portfolios. It provides real‑time insights into stock trades, portfolio performance, and market trends, all in one place.

✨ Features
Portfolio Tracking → Monitor buy/sell trades with FIFO matching logic.

Data Sync → Automated pipeline from Google Sheets → PostgreSQL.

Dashboard → Interactive web interface with filters and charts.

Analytics → Gain/loss calculations, ranking logic, and trend analysis.

Automation → Scheduled refresh and error‑handled ETL scripts.

🛠️ Tech Stack
Backend: Python, PostgreSQL

ETL: Google Sheets API, Pandas

Frontend/Dashboard: Power BI / Streamlit / Dash (open source options)

Deployment: Docker, GitHub Actions (CI/CD)
